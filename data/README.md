# Data

* `lexicon.tsv` — hand-entered seed lexicon (unverified). Highest built-in priority.
* `lexicon_wiktionary.tsv` — derived from English Wiktionary, licensed **CC BY-SA 4.0**
  (https://creativecommons.org/licenses/by-sa/4.0/), extracted by Wiktextract / kaikki.org
  (Ylonen, T. 2022. Wiktextract: Wiktionary as Machine-Readable Structured Data. LREC 2022).
  Regenerate with the "Build Wiktionary Urdu lexicon" GitHub workflow.
* `profiles.json` — regional pronunciation profiles.
